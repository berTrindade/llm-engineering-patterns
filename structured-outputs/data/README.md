# Data

All 50 cases in `cases.jsonl` are invented. No real supplier, company or person is represented.
Supplier names, item descriptions and amounts are made up for this project.

Generated by `src/structured_outputs/generator.py`, a seeded pure-python generator with no LLM
involved (seed `42`). Run `uv run python -m structured_outputs.generator` to regenerate the file
deterministically; the committed file is the output of that command.

Each line is one JSON case with:
- `case_id`: a stable identifier
- `invoice`: the ground-truth `Invoice` fields
- `email_text`: a messy rendering of the same invoice as an email a supplier might send

The generator deliberately varies:
- date formats: `3rd March 2026`, `03/03/26`, `2026-03-03`
- currency renderings: `£`, `GBP`, `EUR`, `€`, `$`, `USD`
- line items as a plain-text table, a bullet list, or a prose sentence
- VAT stated as its own line or left implicit (only subtotal and total shown)
- PO number present or absent
- forwarded-email headers and a signature block, on roughly half the cases each
