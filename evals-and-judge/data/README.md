# Data provenance

All data in this repository is invented for this proof of concept.

- `policy.md` is an invented policy for a fictional shop, "Northwind Home". It does not describe
  any real company.
- `replies.jsonl` is generated by [`src/evals_judge/dataset.py`](../src/evals_judge/dataset.py),
  a seeded, pure-Python generator. No customer, order or reply in it is real; running the
  generator with the same seed reproduces the same file.
- `labels.human.jsonl` holds human pass or fail judgements on the generated replies, made one
  at a time with `make label`. It is committed once labelling is complete, so the judge
  agreement figure in the README can be reproduced.
